# گام ۱ — ارسال با توکن و خواندن اطلاعات عمومی

این عنوان مربوط به برنامهٔ مقدماتی قبلی است. گام ۱ نقشهٔ راه اکانت واقعی اکنون
[شناخت پروتکل](ACCOUNT_STEP_1.md) است؛ قابلیت‌های زیر لایهٔ توکن و صفحات عمومی‌اند.

وضعیت در ۱۵ اکتبر ۲۰۲۶: پیاده‌سازی و ۲۴ تست محلی موفق؛ ارسال واقعی با توکن
هنوز بررسی نشده است. تست‌ها هیچ پیام واقعی ارسال نمی‌کنند.

## این گام چه کاربردی دارد؟

با این لایه می‌توانید برای مقصدی که توکن ایتایار به آن دسترسی دارد پیام متنی یا
فایل محلی بفرستید و اطلاعات صفحه یا یک پست عمومی ایتا را بخوانید. مثلاً برنامه‌ای
که یک گزارش تولید می‌کند، می‌تواند فایل گزارش را همراه توضیح در کانال منتشر کند.
برای خواندن صفحات عمومی به توکن نیاز ندارید.

| قابلیت | کاربرد | خروجی |
| --- | --- | --- |
| `send_message(peer, text)` | ارسال متن؛ پایهٔ `Message.reply()` | `Message` با شناسهٔ تأییدشدهٔ سرور |
| `send_file(peer, file_path, caption=...)` | ارسال فایل یا عکس از مسیر محلی | `Message` همراه `Media` از نوع عمومی `DOCUMENT` |
| `get_chat_info(peer)` | خواندن نام، توضیح، تصویر و اطلاعات نمایشی صفحهٔ عمومی | دیکشنری اطلاعات |
| `get_info(peer)` | نام سازگار برای همان قابلیت قبلی | دیکشنری اطلاعات |
| `get_message(peer, message_id)` | خواندن یک پست مشخص از صفحهٔ عمومی | `Message` یا `None` اگر یافت نشود |

## اجرای نمونه‌ها

از پوشهٔ اصلی پروژه و با محیط پایتون دارای وابستگی‌ها اجرا کنید:

```powershell
python -m pip install -e .
python -m examples.step1 --help
python -m examples.step1 info eitaa
python -m examples.step1 message eitaa 123
```

عدد `123` نمونه است؛ آن را با شناسهٔ یک پست عمومی موجود جایگزین کنید.

برای ارسال، متغیر محیطی `EITAAYAR_TOKEN` را روی دستگاه خود تنظیم کنید؛ توکن را
در کد یا مخزن ذخیره نکنید. دستورهای زیر واقعاً به مقصد مشخص‌شده ارسال می‌کنند؛
`yourchannel` را با مقصد تحت اختیار خود جایگزین کنید:

```powershell
python -m examples.step1 send yourchannel "سلام از کتابخانه"
python -m examples.step1 file yourchannel "C:\reports\report.pdf" --caption "گزارش امروز"
python -m examples.step1 send yourchannel "پاسخ به پست" --reply-to 123
```

## رفتار هنگام خطا

- بدون توکن و اتصال، ارسال با `APIRequestError` متوقف می‌شود.
- فایل ناموجود `FileNotFoundError` می‌دهد؛ شناسهٔ پاسخ نامعتبر `ValueError` می‌دهد.
- پاسخ ناموفق یا فاقد شناسهٔ معتبر، موفقیت ساختگی تولید نمی‌کند.
- هنگام timeout ارسال خودکار تکرار نمی‌شود: ممکن است سرور پیام را پذیرفته باشد
  ولی پاسخ به برنامه نرسیده باشد. پیش از ارسال مجدد، نتیجه را بررسی کنید.
- فایل آپلود پس از موفقیت یا خطا بسته می‌شود و درخواست‌ها timeout دارند.

## مرز این گام با گام بعدی

این لایه با توکن ایتایار کار می‌کند. هنوز ورود با شماره و OTP، فایل سشن اکانت،
خواندن چت خصوصی، حذف/ویرایش یا ارسال آلبوم و ویس تخصصی فراهم نیست.
تصویر پست عمومی در صورت شناسایی در HTML به `MediaKind.PHOTO` تبدیل می‌شود؛
اما ارسال فایل از اندپوینت عمومی فایل استفاده می‌کند و نوع نتیجه فعلاً `DOCUMENT` است.

گام ۲ برای ساخت ورود مستقل به اکانت ایتا و استفادهٔ دوباره از سشن ذخیره‌شده است؛
رویدادها و عملیات خصوصی مراحل بعدی روی همان لایه ساخته خواهند شد.

```powershell
python -m unittest discover -s tests -v
```

بررسی می‌کنند؛ تست موفق محلی جایگزین تأیید ارسال روی سرور واقعی نیست.
