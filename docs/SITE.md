# سایت مستندات Fnc Eitaa

سایت استاتیک فارسی و انگلیسی در `docs/index.html` است. ساخت آن سرویس یا وابستگی
تازه‌ای به SDK اضافه نمی‌کند و هیچ سشن، توکن یا دادهٔ حسابی را باز نمی‌کند.

## پیش‌نمایش

از ریشهٔ مخزن اجرا کنید:

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory docs
```

نشانی محلی: `http://127.0.0.1:8765/#fa/overview`.
برای انگلیسی از `#en/overview` استفاده کنید. مسیرهای hash شامل پیوند بخش‌ها نیز
هستند؛ مثال: `#en/reference/AccountClient-send_message`.

فقط پوشهٔ docs سرو می‌شود؛ از سروکردن ریشهٔ پروژه که ممکن است حاوی سشن باشد خودداری کنید.
بازکردن مستقیم index.html هم ممکن است، ولی clipboard تابع مجوز مرورگر و origin است؛
در صورت نبود امکان کپی خودکار، پیام راهنما نمایش داده می‌شود.

## ویرایش و تولید

- `docs/site_content.py`: محتوای دوزبانه، نمونه‌کدها و توضیح‌های متدها.
- `docs/index.html`: اسکلت صفحه و عناصر دسترس‌پذیری.
- `docs/assets/styles.css`: ظاهر، RTL/LTR، حالت تیره، موبایل و چاپ.
- `docs/assets/app.js`: مسیریابی، جست‌وجو، مرجع، تغییر زبان و کپی کد.
- `docs/assets/content.js`: خروجی تولیدشده؛ آن را مستقیم ویرایش نکنید.
- `tools/build_docs.py`: خواندن AST متدهای عمومی و فیلد dataclassها بدون import کلاینت.

```powershell
python tools/build_docs.py
python tools/build_docs.py --check
```

گزینهٔ `--check` فایل‌ها را تغییر نمی‌دهد و در صورت قدیمی‌بودن خروجی با خطا تمام می‌شود.
پس از تغییر API هم کاتالوگ را دوباره تولید کنید. برای متد تازه توضیح فارسی و انگلیسی
در SUMMARIES اضافه کنید و تفاوت تست محلی و پذیرش زنده را حفظ کنید.

وابستگی CDN، فونت خارجی، telemetry یا اجرای نمونه‌کد در مرورگر وجود ندارد.
انتخاب زبان و پوسته فقط در localStorage همین origin نگه داشته می‌شود؛ اگر مرورگر
ذخیره‌سازی را رد کند سایت همچنان کار می‌کند. جست‌وجو روی محتوا و مرجع به‌صورت محلی است.

## انتشار اختیاری با GitHub Pages

۱. فایل‌های سایت و content.js تولیدشده را در مخزن commit و push کنید.
۲. در Settings → Pages، حالت Deploy from a branch را انتخاب کنید.
۳. شاخهٔ موردنظر و پوشهٔ `/docs` را انتخاب کنید.
۴. پس از آماده‌شدن deployment، نشانی نمایش‌داده‌شدهٔ GitHub را باز کنید.

فایل `.nojekyll` همراه سایت است. مسیر assets نسبی است تا سایت در زیردایرکتوری مخزن
هم کار کند. از branch واقعی خودتان استفاده کنید؛ نام شاخه در این راهنما فرض نشده است.
ساخت محلی سایت، انتشار عمومی آن را انجام نمی‌دهد.

## مرور قبل از انتشار

نصب و ورود را از سشن تازه و آزمایشی دنبال کنید؛ نمونه‌های ارسال را فقط در مقصدی که
اجازه دارید اجرا کنید. لینک‌های داخلی، مسیر انگلیسی، جست‌وجوی متد، نمایش موبایل و
کپی کد را بررسی کنید. فایل سشن و SQLite نباید در پوشهٔ docs قرار بگیرند.
