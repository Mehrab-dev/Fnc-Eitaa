# گزارش بررسی تحویل — ۲۱ اکتبر ۲۰۲۶

اجرای تازه روی کانال تست تأییدشده: **۸۴ بررسی موفق، صفر FAIL، صفر RECONCILED و ۳ SKIP**.
شناسهٔ اجرا: `channel-20261021-115924-7bb405`.
همهٔ بررسی‌های زندهٔ این اجرا با پاسخ قطعی و بازخوانی مستقلِ موارد لازم انجام شدند؛
نتیجهٔ موفق اجرای قبلی برای جایگزینی آزمون تازه استفاده نشد.

## نتیجه‌ها

| بخش | نتیجه |
| --- | --- |
| متن | فارسی، ایموجی، چندخطی، ریپلای و ۴۰۹۶ واحد UTF-16 موفق |
| عملیات | ویرایش متن و کپشن، کپی، فوروارد تکی/چندتایی و حذف تکی/چندتایی موفق |
| مدیا | ارسال و دانلود عکس، فیلم، ویس، سند و فایل چندقطعه‌ای ۲ MiB موفق |
| آلبوم | دو عکس، عکس و فیلم، دو سند و آلبوم صف موفق؛ دانلود تک‌تک اعضا موفق |
| صحت دانلود | اسناد، ویدیو، ویس و فایل چندقطعه‌ای با اصل یکسان؛ عکس خروجی JPEG معتبر |
| رویداد | new/edit/delete، Router، ack و ادامه از checkpoint موفق |
| اطلاعات | حساب، کانال، اعضای قابل‌مشاهده، نقش حساب، گفتگوها و تاریخچهٔ صفحه‌بندی‌شده موفق |
| صف SQLite | ارسال، ویرایش، کپی، فوروارد، انواع مدیا، آلبوم، حذف، لغو و inbox موفق |
| سشن | اتصال مجدد با `.eitaa`، بدون رمز دستی سشن و بدون OTP موفق |
| Client عمومی | خواندن اطلاعات کانال و پیام عمومی موفق |
| تست آفلاین | ۳۶ تست موفق؛ شامل Flood wait ورود، حفاظت سشن، مدیا، رویداد و retry دانلود |
| بسته نصب | ساخت wheel، نصب در پوشهٔ ایزوله، import، دادهٔ پروتکل و رفت‌وبرگشت سشن مصنوعی موفق |
| مستندات | ۱۷ صفحهٔ دوزبانه، ۱۰۹ API، ۲۱ مدل و صحت نحو ۳۰ نمونهٔ Python بررسی شد |
| برنامهٔ اصلی | اجرای واقعی `python main.py` با خروج صفر؛ پیام آزمایشی با شناسهٔ ۸۶ ارسال شد |

۳۶ پیام مصنوعی در این اجرا ساخته شدند؛ ویرایش و حذف فقط روی پیام‌های همین اجرا بود.
صف خروجی: ۱۰ confirmed و یک cancelled. صف ورودی: یک done و ۹ pending که
عمداً پردازش نشده‌اند و خطای تست نیستند. پیام‌های باقی‌مانده برای بررسی ظاهری حفظ شدند.

## اصلاح‌های انجام‌شده

- سشن `.eitaa` با حفاظت سیستم‌عامل، بدون درخواست رمز دستی؛ ویندوز از DPAPI حساب جاری استفاده می‌کند.
- سازگاری با اندازهٔ صفرِ بندانگشتی در پاسخ عکس و آلبوم؛ انتخاب اندازهٔ کامل قابل دانلود.
- تشخیص ویرایش‌هایی که سرور در `new_messages` برمی‌گرداند و حذف رویداد تکراریِ همان ویرایش.
- تلاش محدود برای خواندن قطعهٔ دانلود در خطای اتصال یا HTTP 5xx؛ خطاهای صریح محدودیت تکرار نمی‌شوند.
- پنجرهٔ آزمون رویداد متناسب با فاصلهٔ ۱۲۰ ثانیه‌ای پیشنهادی سرور تنظیم شد.
- نصب مستقیم از GitHub، مهاجرت سشن قدیمی، اجرای نمونه‌ها و محدودیت‌ها مستند شدند.

نمایش شماره و حذف تأیید yes/no ورود، مدیریت Flood wait و سازگاری پاسخ تمدید توکن
نیز در تست‌های فعلی بررسی شدند. درخواست کد ورود واقعی جدید برای تست انجام نشد.

## اجرا روی سیستم مدیر

پوشهٔ سورس را باز کنید؛ Python 3.10 یا جدیدتر لازم است:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install .
.\.venv\Scripts\python.exe -m examples.account_login --live
```

مدیر باید با حساب خودش وارد شود. سشن واقعی همراه بسته تحویل نیست و سشن ویندوز
به حفاظت حساب/سیستم اصلی وابسته است. فایل سشن، صف و checkpoint را ارسال نکنید.
روی macOS/Linux وجود مخزن امن و بازشدهٔ سیستم‌عامل برای نگهداری کلید لازم است؛
اجرای واقعی فعلی روی Windows با Python 3.13 انجام شده است.

بررسی هماهنگی مستندات از پوشهٔ سورس:

```powershell
.\.venv\Scripts\python.exe tools/build_docs.py --check
```

فایل‌های تست، ابزارهای آزمون زنده و خروجی‌های موقت پس از بررسی و به درخواست مالک
از نسخهٔ تحویلی حذف شدند. اعداد این گزارش نتیجهٔ اجرا پیش از پاک‌سازی‌اند و
به معنی وجود مجموعهٔ تست در نسخهٔ تحویلی نیستند. ابزار ساخت مستندات و نمونه‌ها حفظ شدند.

نصب نسخهٔ منتشرشده از GitHub:

```powershell
python -m pip install "git+https://github.com/Mehrab-dev/Fnc-Eitaa.git"
```

دستور GitHub کد منتشرشده را می‌گیرد؛ تغییرات محلی فقط پس از commit و push در آن قرار می‌گیرند.

## محدودهٔ تأیید

این نتیجه به معنی تضمین نبود هر نوع خطای شبکه یا سرور نیست؛ نسخه همچنان `0.1.0`
و experimental است. موارد SKIP: ارسال با توکن مستقل ایتایار، عملیات مخصوص گروه پایه،
و عملیات مخرب احراز هویت/ایجاد عمدی Flood wait. فایل‌های بزرگ‌تر از ۲ MiB،
همهٔ نقش‌ها و مقصدها، و اجرای واقعی macOS/Linux در این اجرا تأیید نشده‌اند.
ظاهر مدیا در برنامهٔ ایتا، پخش و اعلان‌ها به بررسی انسانی جداگانه نیاز دارند.

خروجی‌های جزئی اجرای زنده و بسته‌های موقت ساخت در پاک‌سازی حذف شدند؛ این گزارش
خلاصهٔ نتیجهٔ ثبت‌شدهٔ آن اجرا است. سشن فعلی و وضعیت صف/checkpoint مالک برای حفظ
ورود و ادامهٔ کار محلی نگه داشته شده‌اند و با `.gitignore` از commit خارج‌اند.
